About E-Learn

A B.Sc. Computer Science college project built to make online learning simple to organise and easy to follow.

What this platform is

E-Learn is a student e-learning platform where courses are broken into short lessons, tracked with a progress bar, and reinforced with graded assignments. It brings course browsing, learning and assignment submission into a single, consistent interface.

Project objective

The goal of this project is to provide students with an organised online learning environment, reduce paperwork and manual tracking of coursework, let instructors and admins manage courses and materials efficiently, and make learning resources easy to find and use.

Benefits of online learning

  • Learn at your own pace, on your own schedule
  • Revisit lessons and materials as many times as needed
  • Clear visibility into deadlines and progress
  • Lower cost and no commute compared to in-person classes
Platform features
  • Course catalog with search and filters
  • Lesson-by-lesson progress tracking
  • Assignment submission and status badges
  • Student dashboard and profile
  • Admin panel for managing the platform
  • Built to connect to a Java Spring Boot + MySQL backend
E-Learn

A college project e-learning platform built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript, ready for a future Java Spring Boot + MySQL backend.
